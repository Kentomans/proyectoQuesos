# Criterios de aceptacion

## Flujo principal
- [ ] El usuario puede abrir la pantalla de inicio.
- [ ] El usuario puede ir a la pantalla de calculo.
- [ ] El usuario puede ingresar litros de leche validos.
- [ ] El usuario puede calcular ingredientes.
- [ ] El usuario puede ver resultados.
- [ ] El usuario puede iniciar un nuevo calculo.
- [ ] El usuario puede consultar ayuda.

## Validaciones
- [ ] El campo de litros es obligatorio.
- [ ] El campo acepta valores numericos.
- [ ] El campo rechaza valores menores o iguales a 0.
- [ ] La app muestra mensajes claros cuando hay errores.

## Resultados
- [ ] La sal se calcula con `litrosDeLeche * 0.02`.
- [ ] El cuajo se calcula con `litrosDeLeche * 0.005`.
- [ ] Los resultados se presentan en tarjetas visuales.
- [ ] No existe boton de guardar.
- [ ] No se guardan resultados.

## Calidad
- [ ] La app compila correctamente.
- [ ] La app puede generar APK debug con Capacitor y Gradle.
- [ ] La APK generada no se sube al repositorio.
- [ ] No hay errores de consola.
- [ ] El diseno es responsivo.
- [ ] La paleta oficial se respeta.
