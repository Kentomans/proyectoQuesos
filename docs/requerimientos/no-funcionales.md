# Requerimientos no funcionales

## Diseno y experiencia
- La interfaz debe ser responsiva.
- Los botones deben ser grandes y faciles de presionar.
- El contraste visual debe permitir lectura comoda.
- Todas las pantallas deben respetar la paleta oficial.

## Calidad tecnica
- El codigo debe ser limpio y mantenible.
- La arquitectura debe separar paginas, servicios y modelos.
- La aplicacion no debe mostrar errores en consola.
- No se debe usar backend, base de datos ni almacenamiento local.

## Accesibilidad
- Los campos deben tener etiquetas claras.
- Las validaciones deben mostrarse de forma visible.
- Los textos deben ser simples y directos.
- La navegacion debe ser predecible.
