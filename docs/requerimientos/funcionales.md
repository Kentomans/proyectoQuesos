# Requerimientos funcionales

## RF-01 Pantalla de inicio
- Mostrar marca visual relacionada con Cheese Calculator sin usar iconos.
- Mostrar nombre de la aplicacion.
- Mostrar boton Comenzar.
- Navegar a la pantalla de calculo.

## RF-02 Pantalla de calculo
- Permitir ingresar litros de leche.
- Validar campo obligatorio.
- Validar valor numerico.
- Validar valor mayor a 0.
- Ejecutar calculos matematicos.
- Navegar a resultados.

## RF-03 Pantalla de resultados
- Mostrar litros ingresados.
- Mostrar sal calculada.
- Mostrar cuajo calculado.
- Usar tarjetas visuales.
- Mostrar boton Nuevo calculo.
- Limpiar resultados y regresar a calculo.
- No guardar resultados.

## RF-04 Pantalla de ayuda
- Explicar funcionamiento de la aplicacion.
- Mostrar formulas matematicas.
- Explicar responsabilidad, inclusion y trabajo colaborativo.
- Usar textos claros y accesibles.
