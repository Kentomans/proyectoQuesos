# Flujo de navegacion

## Flujo principal
```text
Inicio -> Calculo -> Resultados -> Calculo
```

## Flujo de ayuda
```text
Inicio -> Ayuda -> Calculo
Calculo -> Ayuda -> Calculo
Ayuda -> Inicio
```

## Pantallas
- Inicio: presenta la aplicacion.
- Calculo: captura litros de leche y valida entradas.
- Resultados: muestra litros, sal y cuajo.
- Ayuda: explica formulas y valores.
