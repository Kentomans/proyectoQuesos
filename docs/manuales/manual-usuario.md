# Manual de usuario

## Inicio
Al abrir Cheese Calculator se muestra el nombre de la aplicacion y el boton Comenzar. Presiona Comenzar para ingresar a la pantalla de calculo.

## Calcular ingredientes
1. Ingresa los litros de leche.
2. Verifica que el valor sea mayor a 0.
3. Presiona Calcular ingredientes.

## Ver resultados
La pantalla de resultados muestra:
- Litros de leche ingresados.
- Sal calculada.
- Cuajo calculado.

## Nuevo calculo
Presiona Nuevo calculo para limpiar el resultado y regresar a la pantalla de calculo.

## Ayuda
La pantalla Ayuda explica las formulas y los valores del proyecto: responsabilidad, inclusion y trabajo colaborativo.

## Notas importantes
- La aplicacion no guarda resultados.
- La aplicacion funciona de forma local.
- No requiere internet para realizar calculos despues de estar instalada.
