# Manual de usuario

## Cheese Calculator

Fecha de elaboracion: 29 de mayo de 2026  
Version del documento: 1.0  
Aplicacion: Cheese Calculator  
Publico objetivo: usuarios que necesitan calcular ingredientes basicos para produccion de queso

## 1. Introduccion

Cheese Calculator es una aplicacion sencilla para calcular la cantidad proporcional de sal y cuajo que se requiere a partir de los litros de leche ingresados.

La aplicacion esta pensada para usarse como apoyo rapido. No reemplaza la experiencia tecnica del productor ni las indicaciones especificas de una receta o proceso industrial.

## 2. Que puede hacer la aplicacion

Con Cheese Calculator puedes:

- Ingresar la cantidad de litros de leche.
- Calcular ingredientes de forma automatica.
- Consultar la cantidad estimada de sal.
- Consultar la cantidad estimada de cuajo.
- Iniciar un nuevo calculo cuando lo necesites.
- Revisar una pantalla de ayuda con pasos y formulas.

## 3. Que no hace la aplicacion

La aplicacion no:

- Guarda resultados.
- Crea historial de calculos.
- Requiere iniciar sesion.
- Usa internet para realizar los calculos.
- Se conecta a una base de datos.
- Ajusta recetas por tipo de queso.
- Sustituye recomendaciones profesionales de produccion.

## 4. Requisitos para usarla

Para usar la aplicacion necesitas:

- Tener la aplicacion abierta en navegador o dispositivo movil.
- Conocer la cantidad de litros de leche que deseas usar.
- Ingresar un valor numerico mayor a 0.

## 5. Pantallas principales

### Inicio

La pantalla de inicio muestra:

- Nombre de la aplicacion.
- Descripcion breve.
- Boton Comenzar.
- Boton Ayuda.
- Indicadores visuales de leche, sal y cuajo.

Desde esta pantalla puedes iniciar el calculo o consultar ayuda.

### Calculo

La pantalla de calculo permite:

- Escribir los litros de leche.
- Ver una indicacion de ejemplo.
- Enviar el formulario con el boton Calcular ingredientes.
- Ir a la pantalla de ayuda si tienes dudas.

### Resultados

La pantalla de resultados muestra:

- Litros de leche ingresados.
- Sal calculada.
- Cuajo calculado.
- Aviso de que los valores son referenciales.
- Boton Nuevo calculo.

### Ayuda

La pantalla de ayuda muestra:

- Pasos para usar la aplicacion.
- Formulas utilizadas.
- Recomendaciones de responsabilidad.
- Informacion de accesibilidad.
- Enlaces para volver a calcular o regresar al inicio.

## 6. Flujo general de uso

```text
Inicio -> Calculo -> Resultados -> Nuevo calculo -> Calculo
```

Tambien puedes consultar ayuda desde:

```text
Inicio -> Ayuda
Calculo -> Ayuda
Ayuda -> Inicio
Ayuda -> Calculo
```

## 7. Como realizar un calculo

1. Abre Cheese Calculator.
2. En la pantalla de inicio, presiona Comenzar.
3. En la pantalla de calculo, localiza el campo Litros de leche.
4. Escribe la cantidad de leche que usaras.
5. Verifica que el numero sea mayor a 0.
6. Presiona Calcular ingredientes.
7. Revisa los resultados en la pantalla Resultados.

## 8. Ejemplo de uso

Si ingresas:

```text
10 litros de leche
```

La aplicacion aplica las formulas:

```text
sal = litros * 0.02
cuajo = litros * 0.005
```

Resultado base del calculo:

```text
sal = 0.2
cuajo = 0.05
```

Nota sobre unidades: la interfaz muestra los resultados con unidades visuales de sal y cuajo. Los valores son referenciales y deben interpretarse de acuerdo con el criterio definido por el equipo o responsable de produccion.

## 9. Validaciones del formulario

El campo Litros de leche tiene reglas para evitar errores:

- No puede estar vacio.
- Debe ser un numero.
- Debe ser mayor a 0.
- El minimo aceptado por la interfaz es 0.01 litros.

Si escribes un valor incorrecto, la aplicacion muestra el mensaje:

```text
Ingresa un numero mayor a 0.
```

## 10. Como iniciar un nuevo calculo

Cuando estes en la pantalla de resultados:

1. Presiona Nuevo calculo.
2. La aplicacion limpia el resultado anterior.
3. Regresaras a la pantalla de calculo.
4. Ingresa una nueva cantidad de litros de leche.

Los calculos anteriores no se guardan.

## 11. Como consultar ayuda

Puedes entrar a Ayuda desde:

- El boton Ayuda en Inicio.
- El boton Ver ayuda en Calculo.

Dentro de Ayuda puedes:

- Revisar los pasos de uso.
- Leer las formulas.
- Volver a calcular.
- Regresar al inicio.

## 12. Mensajes y situaciones comunes

| Situacion | Que significa | Que hacer |
| --- | --- | --- |
| El campo esta vacio | No se ingreso cantidad de leche. | Escribe un numero mayor a 0. |
| Aparece mensaje de error | El valor no cumple las reglas. | Revisa que sea numerico y positivo. |
| La app vuelve a Calculo desde Resultados | No hay calculo activo en memoria. | Realiza un calculo nuevo. |
| Se perdio el resultado al recargar | La aplicacion no guarda datos. | Ingresa nuevamente los litros de leche. |

## 13. Recomendaciones de uso

- Usa datos reales y revisados.
- Verifica que los litros de leche correspondan a tu produccion.
- Toma los resultados como referencia de apoyo.
- Consulta la receta o proceso especifico si el tipo de queso requiere ajustes.
- Realiza un nuevo calculo si cambias la cantidad de leche.

## 14. Accesibilidad

La aplicacion fue diseñada para facilitar el uso:

- Botones grandes.
- Textos claros.
- Contraste visual alto.
- Validaciones visibles.
- Navegacion sencilla.
- Interfaz adaptable a distintas pantallas.

## 15. Privacidad y datos

Cheese Calculator no solicita datos personales.

La aplicacion no guarda:

- Nombre del usuario.
- Historial de calculos.
- Cantidad de leche ingresada despues de cerrar o recargar.
- Resultados anteriores.

Los calculos solo permanecen temporalmente mientras se navega dentro de la aplicacion.

## 16. Solucion de problemas

### No puedo avanzar a resultados

Revisa que el campo Litros de leche tenga un numero mayor a 0.

### El resultado desaparecio

La aplicacion guarda el calculo solo en memoria. Si recargas la pagina o sales de la app, debes calcular otra vez.

### El resultado parece diferente a mi receta

Las formulas son proporcionales y generales. Algunas recetas cambian segun tipo de queso, temperatura, leche, cuajo o tecnica utilizada.

### No encuentro el boton de ayuda

En Inicio aparece como Ayuda. En Calculo aparece como Ver ayuda.

## 17. Glosario

Litros de leche: cantidad de leche que se usara como base del calculo.  
Sal: ingrediente calculado con la proporcion definida en la aplicacion.  
Cuajo: ingrediente utilizado para apoyar la coagulacion de la leche.  
Calculo activo: ultimo resultado guardado temporalmente mientras se usa la app.  
Nuevo calculo: accion que limpia el resultado anterior y permite ingresar otro valor.

## 18. Cierre

Cheese Calculator esta pensada para ser una herramienta rapida, clara y facil de usar. Su flujo principal es corto: ingresar litros, calcular ingredientes, revisar resultados e iniciar otro calculo si es necesario.
