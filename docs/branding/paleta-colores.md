# Paleta de colores

## Variables oficiales
```scss
--color-cafe-principal: #8C774C;
--color-cafe-oscuro: #595242;
--color-crema: #F2E7D0;
--color-amarillo-suave: #FFE2A8;
--color-amarillo-queso: #FFCF6A;
```

## Uso recomendado
- `#FFCF6A`: botones principales.
- `#595242`: textos principales.
- `#8C774C`: encabezados.
- `#F2E7D0`: fondo principal.
- `#FFE2A8`: tarjetas y secciones.

## Reglas visuales
- No usar colores fuera de la paleta salvo blanco para contraste puntual.
- Mantener buen contraste en textos.
- Mantener botones grandes y claros.
- No usar iconos en la interfaz.
