Como funciona

La app recibe los litros de leche y calcula ingredientes usando proporcionalidad directa.

Formulas

Sal = litros de leche x 0.02

Cuajo = litros de leche x 0.005

Responsabilidad

Usar datos correctos ayuda a tomar mejores decisiones durante la produccion.

Inclusion

La interfaz usa textos claros, buen contraste y botones grandes para facilitar el acceso.

Trabajo colaborativo

El proyecto esta organizado para que cada integrante pueda avanzar sin bloquear a los demas.
